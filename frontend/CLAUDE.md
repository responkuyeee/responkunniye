# Frontend Context & Guidelines

Konteks khusus untuk modul frontend Next.js di platform Marketplace Responden.

## Tech Stack
- **Framework:** Next.js (App Router)
- **UI Library:** React 18
- **Language:** TypeScript
- **Styling:** Modern Vanilla CSS & Design Tokens (Dark theme, glassmorphism, responsive)

## Prinsip Desain & Navigasi
1. **Satu Akun, Dua Peran:** Dashboard memiliki toggle mode Researcher ↔ Respondent.
2. **Auto-Filter:** Responden hanya melihat daftar survei yang profilnya cocok dan sesuai ambang Quality Score.
3. **Kalkulasi Biaya Real-Time:** Form pembuat riset wajib menampilkan estimasi token yang di-reserve (min. 50 responden).
4. **Desain Elegan & Responsif:** Komponen interaktif dengan micro-animations, layout jelas, dan tipografi modern (Inter).
